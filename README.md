# Tarcze — Stop, sprawdzam

Lokalna aplikacja do prezentacji warsztatowej: plansza powitalna, cztery filmy z tarczami i przerywniki. Wszystkie materiały są w repozytorium.

## Uruchomienie

Pobierz repozytorium jako ZIP i rozpakuj. Otwórz `index.html` w przeglądarce. Zachowaj folder `media` obok plików aplikacji. Aplikacja działa bez internetu.

## Sterowanie

- **→** — przejście dalej lub uruchomienie zatrzymanej tarczy.
- **→ podczas przerywnika** — wyciszenie przez 1,4 sekundy i zatrzymanie na pierwszej klatce kolejnej tarczy; następne naciśnięcie uruchamia film.
- **←** — poprzednia plansza, z zatrzymanym filmem.
- **Spacja** — pauza lub wznowienie.
- **F** — pełny ekran; **Esc** — wyjście.

Między czterema tarczami wyświetlane są trzy przerywniki.
